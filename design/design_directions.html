Admin Architecture

Where Admin Pages Live

Two approaches for organizing Admin Panel, Bishop Dashboard, Pastor Dashboard, and Wizard Assignment out of the main nav.

Option A — "Scriptorium" Sidebar Section

Admin pages collapse into a special section at the bottom of the sidebar, locked behind a role check. Only Admins/Bishops/Pastors see it.

All admin tools move inside the existing Settings page as gated tabs. The sidebar stays clean with just 9 regular pages.

Fleet Transitions

Page Transition Options

All three work inside Streamlit using CSS injected via st.markdown(unsafe_allow_html=True)

Fade + Rise

Each page load triggers a 350ms opacity+translateY fade-in. Smooth, subtle, feels like turning a page.

RECOMMENDED · LEAST CODE

Gold Shimmer Bar

A thin gold progress bar sweeps across the top on each navigation — like a page-load indicator but sacred.

VISUAL IMPACT · MEDIUM

Cross-Dissolve

The entire content area fades from black between pages. The most cinematic — requires a JS component wrapper.
